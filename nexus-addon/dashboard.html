Danger zone
Developer / Debug

Reload open game tabs after updating or reloading the extension to ensure diagnostic capture is active. Toggling recording on or off takes effect immediately without reloading game tabs. Recording keeps at most 150 entries per stream and 10 MB of JSON text per server. Entries allow up to 256,000 characters, with explicit markers when content is truncated. Headers, query strings and authentication endpoints are excluded; recognized secrets are redacted. Payloads can still contain private game data: review exports before sharing.

Diagnostic traffic is stored separately from statistics in a local database. Use JSONL export to back up logs; regular data backups do not include them.
