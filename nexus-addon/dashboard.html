What is shared and downloaded?

Downloads contain maintainer-approved galaxy structure. They never mark ownership or explored visibility as known. GitHub receives normal connection information, not your game data.

Exports use saved data only: systems, zones, physical planet/moon properties and station/hub locations. Owners, player data, colony names, resources and upgrade-dependent building-slot values are excluded. Only the maintainer publishes approved additions.

What does a backup include?

Full backups contain saved game data from every server and addon options. Options-only files contain settings, not game data. Developer diagnostic logs are separate JSONL exports and are not included in backups.

Danger zone

Developer / Debug

Reload open game tabs after updating or reloading the extension to ensure diagnostic capture is active. Both recording switches take effect without reloading game tabs. Traffic recording keeps at most 150 entries per stream; wait recording keeps up to 1,000 scheduling events. All streams share a 10 MB limit per server. Traffic entries allow up to 256,000 characters, with explicit markers when content is truncated. Headers, query strings and authentication endpoints are excluded from traffic capture; recognized secrets are redacted. Payloads can still contain private game data: review exports before sharing.

Diagnostic traffic is stored separately from statistics in a local database. Use JSONL export to back up logs; regular data backups do not include them.
